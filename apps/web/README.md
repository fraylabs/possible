# Possible web

- `/` — searchable, paginated Outcome directory
- `/outcomes/<slug>` — result preview, exact prompt, provenance, source, author, Products, and Skills
- `/products/<slug>` and `/skills/<slug>` — source information and related Outcomes
- `/dashboard` — private importing and publishing workspace
- `/docs` — use, publishing, and format reference

The site imports `@possible/catalog`. Outcome media is copied from the owning Outcome folder during development and builds.
