# Outcome Pack authoring fields

Generated from `packages/packs/src/outcome-pack.schema.json`. Do not edit this file by hand.

The JSON Schema owns the complete authoring surface. Identity, release, source, trust, evidence, discovery fixtures, and showcase media live outside `pack.json`.

## Pack

- `schemaVersion` (required) — The Outcome Pack JSON contract version. Use 1.

- `name` (required) — A specific, human-readable name for the finished outcome—not a tool, workflow, or department.

- `promise` (required) — One plain-language sentence saying what the user can expect to have when the pack succeeds.

- `prompt` (required) — The exact, self-contained prompt that asks an agent to produce this concrete outcome. Include the real inputs, deliverables, creative direction, constraints, and finish boundary in the prompt itself; do not turn it into a reusable workflow for a broad class of work.

- `expectations` — Optional. Add only a short checklist of observable acceptance criteria that materially clarify this exact prompt. Omit it when the prompt already says what finished means.

- `skills` — Optional. Add only the smallest set of specialized agent Skills the outcome needs, identified by GitHub repository and directory with the last reviewed commit recorded for provenance. Omit this field when the agent needs no additional Skills.

- `products` — Optional Product attribution. Reference registered Products used by this outcome. Product metadata never replaces Skills or execution instructions.

- `notFor` — Optional nearby requests this pack should not be selected for. Add only boundaries that materially prevent a bad recommendation.

## Skill

- `repository` (required) — The GitHub repository containing the Skill, in owner/repository form.

- `lastReviewedCommit` (required) — The exact lowercase commit last reviewed by the pack author. The standard Skills installer may install a newer upstream version. Never use a branch or tag.

- `directory` (required) — The exact repository-relative directory containing SKILL.md. Use . only when SKILL.md is at the repository root.
