# Score experiment — Strudel

The approved silent film remains unchanged. This experiment adds one original,
code-authored 44-second score for review before audio becomes part of the
Outcome Pack.

## Story shape

- `00:00–00:06.6` — a restrained motif opens inside the familiar code window.
- `00:06.6–00:15.4` — pulse, bass, and harmony expand with the capability world.
- `00:15.4–00:22.0` — percussion drops away so the awareness gap can land.
- `00:22.0–00:30.8` — rhythm returns when Possible organizes the possibilities.
- `00:30.8–00:39.6` — the motif rises as one Outcome Pack unfolds.
- `00:39.6–00:44.0` — the arrangement clears and resolves on the invitation.

The Strudel source is `score/possible-world-score.strudel.js`. It intentionally
uses synthesized sound rather than downloaded music, vocals, ominous ambience,
or generic corporate stock audio.

## Review artifacts

- `assets/audio/possible-world-strudel.wav` — mastered 44-second score.
- `possible-world-inside-codex-strudel.mp4` — scored review cut.
- `possible-world-inside-codex.mp4` — approved silent cut, unchanged.

The review master measures `-19.7 LUFS` integrated with a `-2.4 dBFS` true
peak. This leaves comfortable headroom while keeping the music present in a
film without narration.
